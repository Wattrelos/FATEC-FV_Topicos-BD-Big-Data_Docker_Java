
# Todas as credenciais, senhas, portas e configurações foram transferidas para o arquivo [`.env`]

## O que foi realizado:

1. **Centralização e Segurança no [`.env`](/.env)**:
   - Todas as senhas, nomes de banco, usuários, portas e credenciais de web managers/RabbitMQ agora ficam exclusivamente no `.env`.
   - A senha com caractere especial foi devidamente encapsulada entre aspas para evitar que o `#` fosse interpretado erroneamente como comentário no arquivo de ambiente.
   - O arquivo [`.gitignore`](/.gitignore) já está configurado para proteger o `.env` de ser versionado ou exposto no repositório.

2. **Template Completo em [`.env.example`](/.env.example)**:
   - Criado e versionado como referência para novos ambientes e desenvolvedores (`cp .env.example .env`).

3. **Arquivos Compose Parametrizados com Fallbacks Seguros**:
   - **[docker-compose.yml](/docker-compose.yml)**: Portas da aplicação e credenciais do RabbitMQ usam `${VAR:-default}`.
   - **[docker-compose.mariadb.yml](/docker-compose.mariadb.yml)**: Credenciais de banco, root, portas e phpMyAdmin usam `${VAR:-default}`.
   - **[docker-compose.postgres.yml](/docker-compose.postgres.yml)**: Credenciais de banco, portas e pgAdmin 4 usam `${VAR:-default}`.

4. **Automação no [`start.sh`](/start.sh)**:
   - Se alguém rodar o `./start.sh` em uma máquina recém-clonada (onde o `.env` ainda não existe), o script agora **cria automaticamente o `.env` copiando o `.env.example`**.

5. **Documentação e Walkthrough**:
   - [README.md](/README.md) e [Walkthrough-001.md](/docs/architecture/reviews/Walkthrough-001.md) foram atualizados para documentar a gestão segura das credenciais.
